# Weather App (Python)

A simple Python command-line application that fetches real-time weather data using the OpenWeatherMap API.

## Features
- Get current temperature
- Humidity level
- Weather description
- Feels-like temperature
- Error handling for invalid city names

## Technologies Used
- Python
- Requests library
- OpenWeatherMap API

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Set API key:
   export OPENWEATHER_API_KEY=your_api_key

3. Run the program:
   python weather.py
